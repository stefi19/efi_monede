## 📱 Running on your phone

Make sure your phone and computer are on the **same WiFi network**, then:

```bash
npm run dev
```

Vite will print something like:

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/   ← open THIS on your phone
```

Open the **Network** URL in your phone's browser (Safari on iPhone, Chrome on Android).

### Install as an app (no App Store needed)

**iPhone (Safari):**
1. Open the Network URL in Safari
2. Tap the Share button (□↑)
3. Tap **"Add to Home Screen"**
4. Done — it opens fullscreen like a real app 🎉

**Android (Chrome):**
1. Open the Network URL in Chrome
2. Tap the three dots menu
3. Tap **"Add to Home Screen"** or **"Install app"**
4. Done 🎉
